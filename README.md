# SMART-RC-ARDUINO-CAR-
Use Arduino to read signal from RC transmiter, program some smart features to support in the way to control can support to avoid obstacle.

## Features
-Control by RC Transmiter
-Support Obstacle Avoidance 

## Hardwware

|Component| Model | Quantity |
|---------|-------|----------|

|Arduino| Uno R3 | 1 |
|L298N | Motor Driver | 2 |
|DC Motor | 12v | 4 |
